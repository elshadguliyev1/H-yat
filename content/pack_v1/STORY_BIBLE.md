# Hekayə bələdçisi

Dil: təbii Azərbaycan dili, qısa, təsirli, süni melodramdan uzaq. Dialoqlar personajın yaşına, təhsilinə və mühitinə uyğun olsun. Stereotiplərdən qaç. Məktəb, ailə, imtahan, iş, maddi sıxıntı, hərbi həyat, evlilik, boşanma, övladlar, qocalıq kimi mövzular müxtəlif nəticələrə açıqdır. Hər hadisə: məkan + konkret konflikt + 2–4 məntiqli seçim + dərhal nəticə + mümkün gecikmiş toxum.

Təsvir üslubu: statik 2D painterly storybook, solğun göy, isti bej, günbatımı narıncısı; mətn şəkilin daxilində deyil UI-da; 16:9 fon, 1:1 portret. Müasir Azərbaycan məişətinin həqiqi detalları, lakin loqo və real şəxslər yoxdur.
